# Data-Classification-Using--AI
A basic AI classification model using the Iris dataset and K-Nearest Neighbors algorithm.# Data Classification Using AI

## 📌 Project Overview

This project demonstrates the implementation of a basic **Artificial Intelligence classification model** using supervised learning.

The main objective is to train a machine learning model to identify patterns in data and classify new information into predefined categories.

The project follows a complete basic machine learning workflow, from dataset loading and preprocessing to model training, evaluation, and prediction.

---

## 🎯 Objectives

- Load and understand a dataset
- Prepare data for machine learning
- Split the dataset into training and testing sets
- Apply a classification algorithm
- Train the machine learning model
- Evaluate model performance
- Predict the class of new data

---

## 🗂️ Dataset

This project uses the **Iris Dataset**, a well-known dataset for classification tasks.

The dataset contains **150 records** with four numerical features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Classes

The flowers are classified into three categories:

- 🌸 Setosa
- 🌸 Versicolor
- 🌸 Virginica
